## 性能考虑

### 内存管理

| 组件 | 内存占用 | 优化策略 |
|-----|---------|---------|
| Content Script | ~5-10 MB | 队列限制 50 条 |
| Service Worker | ~20-30 MB | 定期清理过期数据 |
| Side Panel | ~10-15 MB | 虚拟滚动（未来） |
| Backend Server | ~50-100 MB | 流式处理 |

### 网络优化

- **批量请求**: 推文最多累积 10 条或 5 秒后批量发送
- **请求合并**: 多个信号类型在一次查询中获取
- **缓存策略**: 服务 Worker 缓存 API 响应（未来）

### 数据库优化

- **索引优化**: 为常用查询字段建立索引
- **定期清理**: 每小时自动清理过期信号
- **分页加载**: 默认限制返回 50 条信号

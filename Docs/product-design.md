# Trend Signal Free (TSF) - 产品设计方案

## 非侵入式智能标记系统

> **核心理念**: 一个好的AI Agent应该像一个默默工作的助手，而不是一个需要你随时关注的工具。

---

## 设计原则

### 1. 自主性 (Autonomy)
- 用户授权后，Agent自动工作
- 通过观察学习，而非询问配置
- 主动推送价值，而非等待查询

### 2. 非侵入式 (Non-intrusive)
- 在原界面添加标记，不替换
- 用户可以选择忽略
- 不改变原有的浏览习惯

### 3. 渐进式披露 (Progressive Disclosure)
- 默认显示最少信息（一个星标）
- 用户主动点击才显示详情
- 不会突然弹出大段内容

### 4. 即时价值 (Immediate Value)
- 用户不需要打开任何面板
- 价值就在当前页面上
- 一眼就能看到

---

## 当前问题

用户必须打开侧边栏才能看到信号 → 这违反了"自主Agent"的理念

## 解决方案：原生标记

### 视觉设计

在推文的**右下角行动栏**添加一个微妙的AI推荐指示器：

```
┌─────────────────────────────────────────────┐
│ @username                    ✨ AI推荐        │  ← 微妙的光晕效果
│                                              │
│ 这是一条关于AI Agent的高质量内容...          │
│                                              │
│ 💬 12   🔄 45   ❤️ 234   👁️ 1.2K           │  ← 原有互动按钮
│                                    ⭐ 87    │  ← 在这里添加评分徽章
└─────────────────────────────────────────────┘
```

### 交互设计

**默认状态**：
- 评分 >= 85：显示实心星 ⭐ (高匹配)
- 评分 70-84：显示空心星 ☆ (中等匹配)
- 评分 < 70：不显示（完全隐藏）

**Hover状态**：
- 显示详细解读卡片，包含：
  - 📖 **解读**：这条推文想说明什么（通俗易懂，高中生能理解）
  - 💡 **意义**：为什么值得关注
  - 🎯 **关键洞察**：2-3个要点
  - 简短摘要

**点击状态**：
- 展开完整的分析卡片（内联，不跳转）
- 包含所有详细解读内容
- 可收起/展开

### 3. 样式设计

- 渐变金色背景

- 半透明金色背景

- 浮动显示在指示器旁边

- 金色渐变背景
- 淡入动画

## AI 解读设计

### 解读原则

1. **语言统一**: 所有解读使用**中文**，无论原文是什么语言

2. **受众定位**: 假设读者是**高中生水平**
   - 避免专业术语
   - 用比喻和类比解释复杂概念
   - 通俗易懂但不失准确性

3. **解读结构**:
   - **📖 解读**: 这条推文在讲什么
   - **💡 意义**: 为什么值得关注
   - **🎯 关键洞察**: 2-3个要点
   - **摘要**: 一句话概括

### Prompt 设计要点

```python
# 后端 agent.py 中的 Prompt 包含：

解读要求（重要）:
1. **语言**: 必须使用**中文**进行解读，无论原文是什么语言
2. **受众**: 假设读者是**高中生水平**，用通俗易懂的语言解释
3. **结构**:
   - 先说明"这条推文在讲什么"
   - 再解释"为什么这个问题值得关注"
   - 最后给出"对读者有什么启发"
4. **深度**: 既要通俗易懂，又要传达核心洞察
```

### 示例解读

**原文**: "The new LLM architecture with mixture-of-experts achieves 40% reduction in inference cost while maintaining accuracy."

**AI解读**:
- 📖 **解读**: 这家公司开发了一种新技术，让AI运行更省钱，而且不会变笨
- 💡 **意义**: AI运行成本大幅降低，意味着未来我们可以用更少的钱运行更强大的AI
- 🎯 **关键洞察**:
  - 成本降低40%是个巨大的突破
  - 保持了准确性说明技术已经成熟
  - 这可能会加速AI在各个领域的普及

## 用户体验场景

### 场景1：首次使用

1. 用户安装扩展
2. 授权后，扩展静默运行
3. 用户访问 likes 页面 → 系统学习兴趣
4. 用户继续正常浏览 Twitter
5. 当出现高价值推文时 → 自动显示 ⭐
6. 用户好奇，点击星标 → 展开分析
7. 用户："哦，原来是这样！" → 继续浏览

### 场景2：日常使用

1. 用户打开 Twitter
2. 正常浏览时间线
3. 偶尔看到 ⭐ → 如果感兴趣就点开看
4. 如果不感兴趣 → 忽略，继续浏览
5. 完全不被打断

## 与侧边栏的关系

**侧边栏保留作为"深度视图"**：
- 原生标记：快速提示，不打断浏览
- 侧边栏：集中查看所有信号，深入分析

**两者配合使用**：
1. 用户在时间线上看到 ⭐
2. 如果感兴趣，点击展开看看
3. 想看更多信号？打开侧边栏查看完整列表

3. **社交信号**
   - 如果你关注的人也点赞了，提高权重
   - "你关注的 @xxx 也觉得这条有用"

4. **时间感知**
   - 早晨：推送行业新闻类内容
   - 晚上：推送深度思考类内容
